# Наши книги · BOOX Duo Launcher

Лёгкий офлайн-лаунчер для одной электронной книги и двух читателей. Разработан с учётом **ONYX BOOX DARWIN 9 (Android 11, E-Ink)**.

## Что работает в первой версии

- Две крупные карточки: **Руслан (ReadEra)** и **Анна (AlReaderX Pro)**.
- Автоматический поиск двух читалок по именам, без жёстко заданных package ID.
- Ручной выбор любого установленного приложения для каждой карточки.
- Свои названия и обложки книг (выбор картинки через системные «Файлы»).
- Быстрый запуск других приложений.
- Возможность попробовать назначить лаунчер домашним экраном Android.
- Монохромная E-Ink компоновка без анимаций, рекламы, сети и ненужных разрешений.

**Важное ограничение:** Android не разрешает лаунчеру напрямую читать историю, обложки и текущую страницу внутри ReadEra или AlReaderX. Приложения сами управляют восстановлением последнего чтения. Карточка открывает приложение; будет ли оно сразу на нужной странице, проверяется на устройстве. Если оно открывает библиотеку, лаунчер не может принудительно перейти на страницу без поддерживаемого deep link.

## Установка и первый запуск

1. Собери `app-debug.apk` (ниже описаны варианты) и перенеси его на BOOX.
2. Разреши установку APK из выбранного файлового менеджера (если Android запросит), установи приложение «Наши книги».
3. Открой его. При наличии ReadEra и AlReaderX Pro они подставятся автоматически.
4. Если приложение не выбралось, нажми **Настройки книг → Выбрать приложение** и выбери нужную читалку.
5. В тех же настройках можно указать название и обложку каждой книги.
6. Открой по очереди карточки — проверь, возвращает ли каждая читалка к последней книге.
7. Лишь после проверки, при желании: **Настройки книг → Выбрать домашний экран Android**. На некоторых прошивках BOOX смена HOME заблокирована — это нормально, оболочку можно запускать как обычное приложение.

**Не удаляй стандартный лаунчер BOOX**, не отключай системные приложения и не меняй прошивку ради этого проекта.

## Сборка APK

### Через GitHub Actions (удобнее всего)

1. Создай новый репозиторий на GitHub и загрузи содержимое этой папки **в корень репозитория**, включая скрытую папку `.github`.
2. Открой вкладку **Actions** → **Build Android APK** → **Run workflow** (или дождись автоматической сборки при push в main/master).
3. После успешной сборки открой запуск Actions и скачай артефакт `BooxDuo-debug-apk`.
4. Распакуй ZIP: внутри `app-debug.apk`, готовый к установке.

### Через Android Studio

1. Открой папку проекта в Android Studio (JDK 17, Android SDK API 35).
2. Синхронизируй Gradle и выбери **Build → Build APK(s)**.
3. APK будет находиться в `app/build/outputs/apk/debug/app-debug.apk`.

Ни одна из этих сборок не требует root на BOOX. `debug`-APK подходит для личной установки и тестирования; для публичной публикации нужен подписанный `release`-APK.

## Архитектура

- Нативный Java Android Activity, без внешних UI-библиотек.
- Android SDK: min 26, target 32, compile 35.
- Только `<queries>` на `ACTION_MAIN + LAUNCHER`, без `QUERY_ALL_PACKAGES`.
- Настройки в `SharedPreferences`; выбранные обложки загружаются через Storage Access Framework.
- Нет разрешений `INTERNET`, доступа ко всем файлам, Accessibility, `SYSTEM_ALERT_WINDOW`, root.
- Имя пакета: `kz.gilmiyarov.booxduo`.

## Что имеет смысл улучшить после теста на Darwin 9

1. Добавить поддержку прямой ссылки на конкретную книгу — **только если** используемые версии ReadEra / AlReaderX предоставляют доступный внешний intent/deep link.
2. Проверить UX назначения HOME через настройки прошивки BOOX.
3. Добавить настоящие обложки из поддерживаемого открытого каталога книг (без чтения приватной базы чужих приложений).
4. Доработать размеры под фактическую плотность дисплея и поведение аппаратных кнопок.

Локальная компиляция APK в среде создания проекта не была доступна из-за отсутствия Android SDK: исходники и GitHub Actions подготовлены, фактическая сборка/тест на устройстве ещё не подтверждены.

# Проверка первой версии на ONYX BOOX DARWIN 9

## Перед тестированием

Не сбрасывай устройство, не меняй прошивку, не удаляй системный лаунчер BOOX. Сначала проверь новую оболочку как обычное Android-приложение.

## Чек-лист

- [ ] APK установился на Android 11 и запускается без вылета.
- [ ] Главный экран читаем на E-Ink: Руслан / Анна, две карточки, нижние кнопки.
- [ ] ReadEra автоматически обнаружилась или выбирается в настройках.
- [ ] AlReaderX Pro автоматически обнаружился или выбирается в настройках.
- [ ] Нажатие «Руслан» запускает ReadEra.
- [ ] Нажатие «Анна» запускает AlReaderX Pro.
- [ ] Каждая читалка после запуска возвращает к последней книге / позиции (поведение самих читалок).
- [ ] В настройках меняются подписи карточек.
- [ ] Выбор обложки из системных «Файлов» работает; изображение сохраняется после перезапуска.
- [ ] Кнопка «Все приложения» открывает список установленного ПО.
- [ ] После нажатия системной кнопки «Домой» оболочку по-прежнему можно открыть из меню BOOX.
- [ ] При желании: опция выбора домашнего экрана открывает настройки Android. Не назначай оболочку по умолчанию до прохождения предыдущих пунктов.

## Если какая-то читалка открывает библиотеку, а не книгу

Это не ошибка лаунчера сама по себе. Лаунчер запускает официальную стартовую Activity выбранной читалки. Что показывается дальше — зависит от её настроек и от того, сохранила ли она свою сессию. После теста можно проверить наличие поддерживаемого внешнего механизма перехода к конкретной книге.

## Возврат к стандартному BOOX

Если удалось назначить оболочку по умолчанию, в настройках Android выбери прежнее приложение «Главный экран» (или сбрось назначение домашнего приложения у «Наши книги»). Если пункт недоступен в прошивке BOOX, сначала запусти системные настройки из списка приложений. **Не сбрасывай всю книгу ради возврата.**
